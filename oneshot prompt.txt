Core gameplay:

* WASD moves the entire 5×5 platform.
* The platform cannot leave the world boundary.
* The platform has 25 grid cells.
* The center cell is the fortress core.
* Each cell can hold one tower.
* Enemies spawn from the edges of the map and move toward the platform.
* Use simple direct movement toward the platform. Do not use complicated pathfinding.
* If enemies touch the platform/core, they damage platform HP.
* Towers placed on platform cells automatically attack enemies in range.
* Killing enemies gives gold.
* Player can buy towers and place them on empty platform cells.
* Player can drag towers to move them.
* Dragging one tower onto another tower of the same type and same level merges them.
* Merge result: target tower level +1, source cell becomes empty.
* Max tower level is 5.
* Player can buy minions.
* Minions spawn near the platform and automatically fight enemies.
* The game has infinite waves and only ends when platform HP reaches 0.

Responsive UI and Canvas scaling:
This is extremely important.

HTML requirements:

* Include this viewport meta tag:
  `<meta name="viewport" content="width=device-width, initial-scale=1.0">`

Canvas requirements:

* Canvas must visually fill the browser window.
* Use CSS width: 100vw and height: 100vh.
* Use devicePixelRatio correctly.
* Use this approach:

  * canvas.width = window.innerWidth * devicePixelRatio
  * canvas.height = window.innerHeight * devicePixelRatio
  * canvas.style.width = window.innerWidth + "px"
  * canvas.style.height = window.innerHeight + "px"
  * ctx.setTransform(devicePixelRatio, 0, 0, devicePixelRatio, 0, 0)
* Draw using CSS pixel coordinates after applying the transform.
* Do not multiply mouse coordinates by devicePixelRatio when drawing uses CSS pixel coordinates with ctx.setTransform.
* Add a resize handler.
* The game must still work after resizing the browser.
* Do not use a fixed 1920×1080-only layout.
* Canvas must not become blurry on high-DPI screens.

Mouse coordinate requirements:
Use this logic:

* const rect = canvas.getBoundingClientRect()
* mouseX = event.clientX - rect.left
* mouseY = event.clientY - rect.top

If using a camera:

* Convert screen coordinates to world coordinates:

  * worldX = mouseX + camera.x
  * worldY = mouseY + camera.y

UI layout requirements:

* Canvas is the background.
* HTML UI is an overlay above the canvas.
* Use CSS flexbox/grid.
* Use clamp() for font sizes, padding, panels, and buttons.
* Shop buttons must wrap on small screens.
* Menus must stay centered.
* No important button should go off-screen.
* Avoid hard-coded absolute positions that break on resize.
* Use pointer-events correctly:

  * Canvas should receive gameplay input.
  * UI panels and buttons should receive clicks.
* UI must work when the browser window is resized.
